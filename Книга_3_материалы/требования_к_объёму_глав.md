# Обязательные требования к объёму глав

Эта таблица задаёт **обязательный диапазон объёма для каждой главы**. Это не рекомендация и не ориентир «по желанию». При редактуре и сдаче главы её объём должен попадать в указанный диапазон включительно. Нижняя граница обязательна; превышать верхнюю границу можно только после отдельного согласования с автором. Если сцена кажется слишком короткой, расширять её следует содержательными действиями, наблюдениями, описанием среды, физики, быта, эмоций и последствий, а не повторами или пустыми разговорами. Уже написанные диалоги сохранять.

## Правило проверки

Перед завершением каждой главы:

1. Считать слова именно в основном файле `chNN.md` установленным выше способом.
2. Сверить результат с обязательным диапазоном для этой главы. Если глава ниже минимума — продолжать содержательную редактуру; если выше максимума — согласовать с автором, а не урезать автоматически.
3. Внести итоговый подсчёт и кратко описать работу в `история_редактуры_и_требования.md`.
4. Не изменять объём за счёт удаления уже написанных диалогов или пустого раздувания текста. Приоритет — причинность, атмосфера, окружение, действия, простые объяснения физики и быта, реакции и последствия.

Эти индивидуальные диапазоны **заменяют** прежние общие ориентиры вроде «не менее 4000», «5000–6500» и «6000–10000 слов для всех глав». Для каждой главы действует только её строка таблицы.
